GanzBot Jr Jr

A two-wheeled self-balancing robot with brushless FOC motor control with realtime wifi data monitoring and motion control.

Started June 2026 Finished August 2026 Stack RP2350 · SimpleFOC · C++

Demo

Overview

GanzBot is a self-balancing robot utilizing WiFi connections to multiple devices. Unlike many robots of its kind using DC or stepper motors, GanzBot uses two brushless DC motors commanded using Field-Oriented Control (FOC). This allows for smooth and low-noise torque control at low speeds.

Sensing and control run on a dual-core RP2350, with the two cores split so the FOC current loop isn't fighting IMU polling and WiFi telemetry for CPU time. Like many self-balancing robot, GanzBot utilizes a cascaded control loop. The inner is running at 200Hz, keeping it upright based on the output of the custom complementary filter calculated on raw IMU data. The outer is keeping the velocity at its desired rate, whether that means staying in place or following a commanded linear velocity.
